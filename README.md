# AI_CONTEXT — あやともについての共有コンテキスト

このリポジトリは、あやとも本人との過去の会話で共有された情報を整理し、別のAI・アシスタントが会話や作業を引き継ぎやすくするための資料です。

## AIへの読み込み指示
1. 最初にこのREADMEを読む。
2. 依頼に関係する資料を読む。全体像が必要なら全ファイルを読む。
3. 「確定」「検討中」「過去・保留」を区別し、古い計画を現在の決定として扱わない。
4. 新しい会話で本人が訂正した場合は、本人の最新の発言を優先する。
5. ここにないことを推測で補わない。重要な不明点だけ質問する。
6. 本人は一緒に考えながら具体化する進め方を好む。提案は現実的・具体的にし、選択肢を大量に並べすぎない。
7. 健康・医療などのセンシティブな詳細はこの資料には含めない。必要な場合は本人に確認する。

## 情報の扱い方
- **確定**：本人が決めた、または明確に述べた内容。
- **検討中**：候補・希望・比較中の内容。決定扱いしない。
- **過去**：以前の計画や環境。現在も有効か確認する。
- **推定**：会話から読み取れる傾向。事実と混同しない。

この資料は会話の要約であり、本人の全情報を網羅するものではありません。
