# 機能一覧

| 機能 | 状態 | 根拠・残課題 |
|---|---|---|
| ペーパー口座 | 確認済み | 現金1,000 USDT、保有なし、取引0件 |
| 資産履歴保存 | 確認済み | SQLiteに初回1件 |
| 総資産計算 | コード確認 | 現金＋保有数量×価格。価格欠損時の扱いを要改善 |
| 日次損失ガード | 編集実施 | UTC日付の開始資産と比較。発動試験未確認 |
| Streamlit画面 | 起動・編集作業実施 | 最終版の全画面動作は要確認 |
| Plotly資産推移 | 編集実施 | 複数履歴での表示を要確認 |
| AI分析・判断表示 | 開発対象 | 最新API設定、応答形式、障害時挙動を要確認 |
| AI組織会議 | 設計方針決定 | 未実装扱い |
| スマホ遠隔操作 | 計画 | 未実装扱い |
| 実取引 | 対象外 | ペーパー段階では実注文禁止 |

## 資産履歴の確認値

`equity_history` の初回レコード: id=1、cash=1000.0、positions_value=0.0、equity=1000.0、holdings_json={}。

利益が出たことや売買処理の正常性を示す結果ではない。
